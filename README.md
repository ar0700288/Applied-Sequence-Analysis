# Applied Sequence Analysis

Projects that work directly with DNA or RNA sequencing reads. Each folder links to its own
repository with the full code, results and documentation.

| Project | Summary |
|---|---|
| [loxhd1-repro](https://github.com/ar0700288/loxhd1-repro) | Reproduction of the LOXHD1 canine deafness variant pipeline (Hytönen et al. 2021) using real SRA data, with clearly labelled stand-ins for private inputs. |

## Note

The project folders are links (git submodules) to the original repositories. To download a
collection together with all its projects:

```bash
git clone --recurse-submodules <this repository URL>
```
